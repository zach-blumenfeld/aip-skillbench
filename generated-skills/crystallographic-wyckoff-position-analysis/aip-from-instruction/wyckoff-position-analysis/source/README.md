## Implementation rationale

- **CIF parsing + symmetry + Wyckoff in one library.** `pymatgen` is the
  canonical choice: `CifParser` reads SHELX/Materials-Project CIFs,
  `SpacegroupAnalyzer.get_symmetrized_structure()` produces both
  `equivalent_sites` (one list per Wyckoff orbit) and `wyckoff_symbols`
  (strings like `"4a"`, `"8c"`). Alternatives (`spglib`, `gemmi`) require
  more glue.
- **Wyckoff letter as key.** The example output keys by letter
  (`"a"`, `"c"`), not by full symbol. Regex-split the symbol into
  `(multiplicity, letter)`.
- **Representative coordinates.** Take the first site in each orbit and
  format its `frac_coords` as low-denominator rationals.
- **Rational formatting.** `Fraction(x).limit_denominator(12)` gives the
  closest rational with denominator ≤ 12. Wrap into `[0, 1)` first so
  coordinates that the symmetry expansion places at, e.g., `-1/2` come
  out as `"1/2"`. After `limit_denominator`, take `numerator %
  denominator` to wrap `1/1` back to `0/1`. Print bare integer when the
  denominator is 1 (matches example `"0"` rather than `"0/1"`).
