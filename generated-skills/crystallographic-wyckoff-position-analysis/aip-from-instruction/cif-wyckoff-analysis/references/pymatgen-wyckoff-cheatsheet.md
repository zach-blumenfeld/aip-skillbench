# pymatgen Wyckoff analysis — cheatsheet

Load on demand when constructing or debugging the Wyckoff extraction logic.

## Core APIs

- `pymatgen.io.cif.CifParser(path)` — parses a CIF file. Use
  `parser.parse_structures(primitive=False)` on modern pymatgen (>= 2024.x)
  or fall back to `parser.get_structures(primitive=False)` for older
  installs. Pass `primitive=False` to keep the conventional unit cell —
  Wyckoff symbols are defined against the conventional setting, not the
  primitive one.

- `pymatgen.symmetry.analyzer.SpacegroupAnalyzer(structure, symprec=0.01)`
  — symmetry detection. Default `symprec` is fine for clean CIFs from
  Materials Project; loosen to 0.1 only if symmetry detection fails on
  noisy experimental data.

- `analyzer.get_symmetrized_structure()` — returns a
  `pymatgen.symmetry.structure.SymmetrizedStructure`. The two attributes
  you need:
  - `.equivalent_sites: list[list[PeriodicSite]]` — each inner list is
    one Wyckoff orbit (all sites generated by symmetry from one
    asymmetric-unit atom). `len(orbit)` equals the Wyckoff multiplicity.
  - `.wyckoff_symbols: list[str]` — one symbol per orbit, e.g. `"4a"`,
    `"8c"`. The numeric prefix is the multiplicity; the trailing letter
    is the Wyckoff label.

## Symbol parsing

A Wyckoff symbol always has the form `<digits><letter(s)>` — strip the
digits to get the label, parse the digits to get the multiplicity. Use
`len(orbit)` as a cross-check; they must agree.

## Coordinates

`PeriodicSite.frac_coords` returns a length-3 numpy array of fractional
coordinates in the conventional cell. Values may sit just outside
`[0, 1)` due to symmetry operations — fold with `value % 1.0` before
converting to a rational.

## Rational rounding

The task constrains denominators to <= 12. Use
`fractions.Fraction(value).limit_denominator(12)`. Notes:
- `Fraction(0).denominator == 1` — print as `"0"`, not `"0/1"`, to match
  the worked example.
- `limit_denominator` uses Stern-Brocot continued fractions and returns
  the closest rational under the cap — exactly what crystallographic
  rounding expects.

## Common pitfalls

- **Primitive vs conventional cell.** Forgetting `primitive=False` can
  shift atoms into a smaller cell with different Wyckoff letters. Always
  use the conventional setting.
- **`get_space_group_symbol` ≠ Wyckoff source of truth.** The space-group
  string is informational; the Wyckoff data lives on the symmetrized
  structure.
- **Symbol collisions.** If two distinct species sit at different
  positions sharing the same Wyckoff letter, `wyckoff_symbols` lists the
  symbol twice. The task's output dict is keyed by letter, so keep the
  first occurrence and skip the duplicate — do not overwrite.
- **Floating-point near-zero.** `frac_coords` like `-1e-17` should fold
  to `0`, not `12/12` or some artifact. Modular folding (`% 1.0`)
  followed by `limit_denominator(12)` handles this cleanly.
